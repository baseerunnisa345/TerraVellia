    How to publish
    1. Download the article HTML and the images ZIP from the pre-flight section above.
    2. Unzip the ZIP into the repo root — files land in articles/<slug>/index.html and assets/img/<slug>/.
    3. Replace data/articles.json and sitemap.xml with the downloaded versions.
    4. Paste the listing snippet between the LISTING:START/END markers on the homepage and the category page.
    5. Commit and push: git add . && git commit -m "Add <slug>" && git push — Vercel auto-deploys.
    6. Check the live article, then pin it from the page using the Save buttons.
